# AgriVision Master Changelog

## [2.5.0] - 2026-09-18
### Added
- DGCA 15-Point Pre-Flight Safety Inspection SOP checklist.
- Pre-Flight Mission Readiness Status Card React component with GNSS satellite check.
- Normalized Difference Moisture Index (NDMI) service with NIR/SWIR band calculation.
- Hargreaves-Samani temperature-based Evapotranspiration (ETo) service.
- Cadastral map DMS to decimal coordinate converter utility.
- ICAR 6 critical growth stages for wheat irrigation reference guide.

## [2.4.0] - 2026-09-17
### Added
- Three.js 3D Farm Digital Twin with autonomous drone simulation and LiDAR scanning cone.
- 3D Wheat Leaf Fungal Lesion Inspector component.
- Autonomous Waypoint Flight Mission Planner.
- Precision Chemical Dosage Calculator.
- Agricultural Spraying Weather Radar with Delta T index.
- Pytest unit test suite with 25 passing test cases.
- Multi-stage Docker production deployment and GitHub Actions CI/CD pipeline.
