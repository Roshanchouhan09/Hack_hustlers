# LoRaWAN 865-867 MHz Indian Frequency Band Specifications

For rural agricultural IoT deployments across India, telemetry nodes operate within the license-free 865-867 MHz band:
- **Channels**: 8 channels (865.0625 MHz to 866.4625 MHz).
- **Spreading Factor**: Adaptive Data Rate (ADR) SF7 (5470 bps, max range 4km) to SF12 (250 bps, max range 14km line-of-sight).
- **Transmit Power**: +20 dBm (100 mW EIRP) with helical brass coil antennas.
- **Sleep Current**: < 2.5 uA using Semtech SX1262 transceiver, enabling 3+ year battery life on a single 3.6V LiSOCl2 ER18505 cell.
